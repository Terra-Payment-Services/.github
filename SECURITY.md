# Security Policy

This policy covers every repository in the TerraPay GitHub organisation that does not carry its own. A repository's own `SECURITY.md`, where there is one, takes precedence for that repository.

## Reporting a Vulnerability

Report security vulnerabilities privately, through either channel:

1. **Email** to [security@terrapay.com](mailto:security@terrapay.com).
2. **GitHub private vulnerability reporting**, using the "Report a vulnerability" button on the repository's Security tab.

Do not open a public issue, discussion or pull request for a security report.

Include the repository, the affected version or commit, a clear description, steps to reproduce and the impact you expect. If the issue also affects the upstream project a repository is built on, say so, and we will coordinate with its maintainers.

## Scope

In scope is the code in TerraPay's repositories, including everything TerraPay changed or added to an upstream project. Out of scope are findings that depend on a deployment someone else has misconfigured, and volumetric denial of service.

If you are unsure whether something is in scope, report it privately anyway.
